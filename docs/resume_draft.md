## 正文（四行版本，可按版面砍到三行）

**HarnessLab —— 带全链路埋点的迷你 Agent 运行时**（Python，个人项目）

- 自研 Agent 主循环（任务 → 上下文组装 → 模型调用 → 工具执行 → 结果回填），
  含 Provider 抽象、工具系统、三级权限门与 SQLite 全链路遥测（会话/轮次/请求/
  工具四表），纯标准库零依赖，42 项离线测试覆盖正常/权限拒绝/故障重试路径；
- 将重试与上下文管理做成可插拔策略并做对照实验：注入连续限流故障下，立即重试
  任务成功率 0%，指数退避 100%（10 任务基准，恢复延迟均值 12.6s）；
- 实现故障注入框架（种子可复现的可调失败率工具 + 按调用序号注入 Provider 故障）
  与 10 项可判分基准（判分器经标准答案反向自检），产出数据化复盘报告与事件流
  毫秒级回放工具；
- 基于自采遥测完成双模型行为对比：推理型模型工具调用量为标准型的 2 倍
  （8.3 vs 4.4 次/任务）而通过率持平；发现任务通过率存在 ~10% 天然波动，
  据此确立多轮均值的方法论。

## 三行压缩版（版面紧张时）

**HarnessLab —— 带全链路埋点的迷你 Agent 运行时**（Python，个人项目）

- 自研 Agent 主循环 + Provider 抽象 + 工具/权限系统 + SQLite 四表遥测，
  纯标准库实现，42 项离线测试全绿；
- 对照实验：注入连续限流下指数退避重试任务成功率 0%→100%（10 任务基准，
  恢复延迟均值 12.6s）；实现种子可复现的故障注入框架与可判分基准；
- 自采遥测量化双模型行为差异（工具调用量 2 倍、通过率持平），发现并论证
  基准需多轮取均值。
